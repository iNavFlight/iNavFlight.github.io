## Introduction

This tutorial is designed for those who:

- Have prior experience with **both INAV multi-rotor and INAV fixed-wing configurations/operations.**
- Know how to create a custom mixer for their model.
- Know basic physics of VTOL operation

## VTOL mode switch operation changes

One of the main things that has changed for all VTOL platforms in INAV 10, is how transition now works on your VTOL mode switch.     
INAV 10 provides the ability to automatically transition from a MC VTOL to a FW or FW to a VTOL hover. However this can still be done by a manual transition with the old legacy method using a 3 Position switch, if desired.  
Using the new 3 Position method, you now move the switch to the middle position from the flight mode state you were in (FW or MC VTOL) and it will commence and complete the transition phase by itself. But you are still required to move the switch to the flight mode position you are selecting, after the transition complete message is displayed on the OSD. Which can be confusing at first.         
But these changes also provide a means to simply transition with a 2 Position switch using `vtol_autotransition_always`. And setting `mixer_vtol_manualswitch_autotransition_controller = ON` in both MixerProfiles. Which is simpler to use and setup. *The diff templates include this method*.   
All you need is one switch position for FW and the other for MC VTOL. Then soon as you move the switch to that position, it will automatically start one full transition cycle, which also uses a timer and virtual airspeed reference to complete the transition.     
What YOU are required to do to use this function, is go to the modes tab and set the RC channel you require to control **Mixer Profile 2 mode**, so that it becomes active when your switch is in the VTOL position, and not active in the FW switch position. The Transition box mode was also added to the template, but not actually required for it to work.

| Name | Description |
| ---- | ------ |
| `mixer_vtol_manualswitch_autotransition_controller` | Starts one automatic VTOL transition each time the switch moves from OFF to ON  |
| `mixer_vtol_transition_airspeed_timeout_ms`  | Maximum wait time [ms] for the required airspeed during an airspeed-controlled transition  | 
| `mixer_vtol_transition_dynamic_mixer`   |  Turns on smooth VTOL transition power and control scaling   |
| `mixer_vtol_transition_scale_ramp_time_ms` |  Controls time-based smooth VTOL motor, power, and transition-servo movement |
| `nav_vtol_mission_transition_min_altitude_cm`  | Do not start a mission-requested VTOL transition below this altitude  |
| `nav_vtol_mission_transition_user_action`  |  Chooses which waypoint USER flag (`USER1`..`USER4`) tells INAV which flight mode to use at each navigable waypoint  | 
| `nav_vtol_transition_fail_action_fw_to_mc`  |  What INAV should do if FW->MC transition fails |
| `nav_vtol_transition_fail_action_mc_to_fw` | What INAV should do if MC->FW transition still fails after the final attemp |
| `nav_vtol_transition_retry_on_airspeed_timeout` |  If ON, INAV gets one extra MC->FW attempt after an airspeed timeout during mission or RTH |
| `vtol_autotransition_always` | When enabled, an armed manual VTOL profile switch between a multicopter-like profile and a fixed-wing profile starts the auto-transition controller instead of switching profiles directly  |
| `vtol_fw_to_mc_auto_switch_airspeed_cm_s` |  Extra low-speed fixed-wing safety fallback |
| `vtol_mc_protection_mode` | Enables extra protection for VTOL aircraft while the active mixer profile is multicopter-like and another mixer profile is fixed-wing  |  
| `vtol_mc_thr_reserve_percent` | Throttle range percentage reserved on both low and high side for VTOL MC attitude authority while navigation/altitude control owns throttle |
| `vtol_transition_fw_authority_min_percent`| Lowest fixed-wing stabilisation used during transition, in percent. In MC->FW, fixed-wing stabilisation starts from this value and rises to full strength as the transition progresses |
| `vtol_transition_lift_min_percent` | Lowest lift motor base throttle used during transition, in percent. This scales the throttle/lift component of MC lift motors, not their roll/pitch/yaw stabilisation correction |
| `vtol_transition_mc_authority_min_percent` | Lowest multicopter stabilisation authority used during transition, in percent |
| `vtol_transition_to_fw_min_airspeed_cm_s`  | Minimum airspeed needed before MC->FW transition is considered complete while a usable transition airspeed source is available |
| `vtol_transition_to_mc_max_airspeed_cm_s` |  When slowing down from FW to MC, the transition is considered complete once airspeed remains at this value or lower for the internal 300 ms confirmation while a usable transition airspeed source is available.|

## VTOL Logic

VTOL functionality is achieved by switching/transitioning between two configurations stored in the FC.
The configurations are defined by the Mixer Profile with its associated Control Profile.

* Mixer profile 1 is for the fixed-wing (FW) flight mode. It is found in the CLI under -  
`# control_profile 1` and `# mixer_profile 1`

* Mixer profile 2 is for the multi-copter (MC) VTOL mode. It is found in the CLI under -  
`# control_profile 2` and `# mixer_profile 2`

* Global Configuration/Settings other than Mixer/control profiles are shared between the two modes. They are found in the CLI under -    
`# master`

![Vtol mixer flow](/img/features-adv/vtol-mixerprofile-flow.png)

### Configuration and setup

When making changes to either MixerProfile in the configurator or the CLI. You are requied to place the relevant changes in to the correct Mixer or Profile.  
Go to the top right corner of the Configurator status bar, next to the Disconnect button. And select either MixerProfile 1 or MixerProfile 2.  
Once you do this. The Configurator will ask you to continue with a reboot. Any changes now made or added to the CLI will be applied to the MixerProfile you just selected.

:::note
Continuous switching back and forth between Mixerprofiles in the Configurator can occasionally cause issues, which prevents the data being saved.    
If this occurs, please close and restart the Configurator and unplug the FC and reboot it.
:::

### STEP 1: Configure as a Normal Fixed-Wing in Profile 1

1. **Select the first Mixer Profile and Control Profile:**
   - In the CLI, switch to the mixer_profile and control_profile you wish to set first. You can also switch
     mixer_profile/control_profile through gui with aforementioned presets loaded.
     ```
     mixer_profile 1 #in this example, we set profile 1 first
     set mixer_pid_profile_linking = ON  # Let the mixer_profile handle the control profile (formerly pid_profile) switch on this mixer_profile
     set platform_type = AIRPLANE
     save
     ```

1. **Configure the fixed-wing/Multi-Copter:**
   - Configure your fixed-wing/Multi-Copter as you normally would, or you can copy and paste default settings to expedite the process.
   - Dshot esc protocol availability might be limited depends on outputs and fc board you are using. change the motor wiring or use oneshot/multishot esc protocol and calibrate throttle range.
   - You can use throttle = -1 as a placeholder for the motor you wish to stop if the motor isn't the last motor
   - Consider conducting a test flight to ensure that everything operates as expected. And tune the settings, trim the servos.

![FW Mixer](/img/features-adv/vtol-mixerprofile-fw-mixer.png)

:::note
You must also assign the tilting servos values using the MAX values.
If you don't do this, the motors will point in the direction assigned by the transition mode.
:::

### STEP 2: Configure as a Multi-Copter in Profile 2

1. **Switch to Another Mixer Profile with Control Profile:**
   - In the CLI, switch to another mixer_profile along with the appropriate control profile.
     You can also switch:
     mixer_profile/control_profile through gui with aforementioned presets loaded.
     ```
     mixer_profile 2
     set mixer_pid_profile_linking = ON
     set platform_type = MULTIROTOR/TRICOPTER
     save
     ```

1. **Configure the Multicopter/tricopter:**
   - Set up your multi-copter/fixed-wing as usual, this time for mixer_profile 2 and control_profile 2.
   - Utilize the 'MAX' input in the servo mixer to tilt the motors without altering the servo midpoint.
   - At this stage, focus on configuring profile-specific settings. You can streamline this process by copying and pasting the default PID settings.
   - you can set -1 in motor mixer throttle as a place holder: this will disable that motor but will load following the motor rules
   - compass is required to enable navigation modes for multi-rotor profile.
   - Consider conducting a test flight to ensure that everything operates as expected. And tune the settings.
   - It is advisable to have a certain degree of control surface (elevon / elevator) mapping for stabilization even in multi-copter mode. This helps improve control authority when airspeed is high. It might be unable to recover from a dive without them.

### STEP 4: Tilting Servo Setup (Recommended)

:::info
Setting up the tilting servos to operate correctly is crucial for correct yaw control of the craft. Using the default setup works, but will most likely result in your craft crawling forward with every yaw input.
:::

The steps below describe how you can fine-tune the tilting servos to obtain the optimum result.

1. **Set the tilt servos at 45 degrees:**
   - Connect and power the tilting servos with your flight controller.
   - Enter transition mode (your switch should be in the mid-position).
   - Check the Outputs tab and make sure that the tilt servo channels are exactly at 1500µs.
   - In this mode, your tilt servos should be at the 45-degree position and you can now mount the motor and prop to your tilt servo such that the angle of the motor mounting plate is at 45 degrees upwards.
   - NOTE 1: If you have dedicated tilt servos, you may have engraved indices on the servos and tilting motor assembly to help you with this step. If the servos don't end up exactly at 45 degrees due to the teeth on the servo and the control arm/plate, don't worry, this will be automatically adjusted after completing the other steps below.
   - NOTE 2: If you are using control rods to adjust the tilt of the servos, adjust the length of your control rod and the position of the control arm to position the control arm as close as possible to the mid position. It will depend on the orientation of the servo, but generally speaking, the control arm of the servo should be pointed perpendicular to the fuselage when the motor mounts are at the 45 degree setting.

2. **Switch to Multicopter/Tricopter:**
   - Assuming that you have set up your mixer similar to STEP1 and STEP2, you can now switch to the tricopter/multicopter mode and your servos should be tilting the motors upwards. If this is not the case, reverse the servo(s) in the Outputs tab such that the servo(s) is/are pointed upwards.
   - It is OK for the servos not to point exactly 90 degrees upwards, but they should be as close as possible to that position.
   - Also, ensure that your MAX values in the Mixer tab are at 100 and -100, so that your servo will move to the maximum position, as shown in the screenshots in STEP1 and STEP2.

3. **Adjust the maximum throws for the Multicopter/Tricopter mode:**
   - While in tricopter mode, navigate to the Outputs tab and adjust the MIN and MAX endpoint values to position the motors slightly backward.
   - Rotate the prop such that it is pointed backwards towards the wing/motor mount and ensure that the gap is the same on both sides by adjusting the MIN and MAX values for the tilt servo channels.
   - NOTE: You can check the distance with calipers or gauge blocks. Alternatively, you can adjust the MIN and MAX for your tilting servos such that the props are just touching the top of the wing or motor mount, and then you can increase/decrease the MIN and MAX values for each channel by the same amount for both servos. This should ensure that you have the same gap between the tip of the prop and the wing or motor mount for both sides.

4. **Adjust the minimum position for the Fixed-wing mode:**
   - Repeat the same step as point 3 with the model in fixed-wing mode, where the servos are tilted forwards.
   - For this step, you just have to make sure that the motors are pointed exactly forwards.
   - You can do this by adjusting the respective MIN and MAX values in the Output tab for the tilt servo channels while in fixed-wing mode.
   - NOTE: Ensuring that your servos are tilted exactly forward is a crucial step as it can cause the plane to roll slightly if that it is not the case. However, ensuring the exact alignment will depend on your specific setup. If you are using dedicated tilting motor servos rather than standard servos with control arms and pushrods, you can make sure that you are exact by measuring the distance between the front edge of the tilting servo and the of the motor mounting plate. If the distances are the uniform across each mount and same on both motors, your servos are pointed forwards correctly.

5. **Adjust the vertical position of the tilt servos:**
   - Switch back to multicopter/tricopter mode and open the Mixer tab.
   - Start adjusting the `MAX` mixer lines from STEP2 such that the servos are pointed exactly upwards. In other words, start reducing the values of 100 and -100 to something like 80 and -80 until the motors are pointed exactly upwards.
   - You will have to `Save & reboot` for adjustment for the changes to take effect, so be patient, take your time and don't forget to `Save & reboot`.
   - Move the YAW stick to either extreme position and ensure that the servos are tilting the motors both forwards and backwards.
   - NOTE: When yawing fully left, the left motor should tilt backwards and the right motor should tilt forwards.

6. **Adjust the throws of the tilt servos:**
   - The final step is to adjust the throws of the servos such that they are the same in both directions.
   - To do this, move back to the Mixer tab while in multicopter/tricopter mode and start adjusting the previously set up 50 and -50 values from the Stabilised Yaw lines.
   - You can try with lower values of about 30 and -30 and then increase the values until you reach the maximum travel point.
   - NOTE: The maximum is reached when both servos are moving the same amount in opposite directions and one servo does not continue to move after the other has stopped.

7. **Check correct operation and direction:**
   - Cycle back and forth between the plane, transition and tricopter modes to make sure that your servos are maintaining the same setting.
   - For the fixed wing setting, your tilt servos should point the motors exactly forwards.
   - For the multicopter/tricopter mode, the tilt servos should point the motors exactly upwards and when moving the yaw stick, both servos should tilt the motors the same amount in opposite directions.

Optional Setup Step for Tilt Servos:

8. **Reversing tilt servos and mixer signs:**
   If you have set up the mixer as suggested in STEP1 and STEP2, you may have to deal with negative values for the mixer. You may wish to reverse a servo so that you don't have to deal with the negative signs. In that case, you may have to adjust the MIN and MAX values from point 4 again, so that your tilt servos are operating correctly. Check the operation of the servos once again for the YAW control in multicopter/tricopter mode as well as the horizontal position of the tilt servos in fixed-wing mode.

### STEP 5: Transition Mixing (Multi-Rotor Profile)(Recommended)

:::info
Transition Mixing is typically useful in multi-copter profile to gain airspeed in prior to entering the fixed-wing profile.
When the `MIXER TRANSITION` mode is activated, the associated motor or servo will move according to your configured Transition Mixing.

Please note that transition input is disabled when a navigation mode is activated. The use of Transition Mixing is necessary to enable additional features such as VTOL RTH with out stalling.

## TailSitter Setup

### Important information

- A Tailsitter requires a minimum of two tractor motors, one on each wing. It will not function correctly using pusher motors.

- Tailsitter VTOL aircraft require high airflow from the propellers over the Elevator and Ailerons.  
Both these control surfaces must also have a minimum of 45° throws in the SMIX of MixerProfile 2. If you do not setup your Tailsitter to provide both of these, the flight controller will not be able to maintain attitude stabilization while hovering or especially descending.

- A Flying Wing platform with large Elevons will provide the greatest chance of success for a Tailsitter VTOL. This is due to each Elevon receiving the full airflow from each propeller. However an airplane with a tail can also be made work, providing the control surfaces are receiving a minimum of 50% of the propellers airflow. But the chances of a successful landing descent will be significantly reduced.

- **Throttle control is of the highest importance for a Tailsitter VTOL**. You must never lower the throtlle more than a few percent below what the Tailsitter requires to hold a stationary hover. Doing so while hovering or landing can lead to reduced airflow over the control surfaces and a loss of attitude control.   
If the aircraft starts to fall out of the hover. Recovery is best performed by increasing the throttle 10 -20% above hover, until it's stable again. Then slowly reduce the throttle back to the hover point again.

:::tip 
Setting up a variometer with audible alert tones on your radio transmitter, based on VSpd. Is a good way to inform you if you're keeping the throttle close to hover.
:::

### Step 1: 

When setting up control surface travels in both mixers. Leave the servo weights in the OUTPUTS tab at 1000 - 2000us. And adjust the servo SMIX weight in MixerProfile 1 & 2 according to the travel required. The MC servo travels as seen in the template are set higher to provide 45° or more control surface throws for VTOL flight. But control surface travels in the FW flight mode may only require 1/3 of that travel to provide smooth stabilization.

Based on the loaded template above. 
Alter the motor and servo mixers according to your requirements in both MixerProfiles, to suit your hardware installation.
You can add more motors MMIX rules if your installation uses e.g. 4 motors.  
And you can add extra Servo SMIX mixer rules for an Elevator (Stabilized Pitch) or Rudder(RC Yaw), if your Tailsitter requires it, or is based on a plane with a tail.

### Step 2: 

Make sure your motor mixer rules for Yaw in MixerProfile 1 and Roll in MixerProfile 2 have the motor weight sign set in the correct direction. (`-0.4  0.4` and `-1.0  1.0`). If the motors are driving the stabilization or stick input e.g right instead of left. Swap the *negative sign* on that mixer.

When a Tailsitter is in a vertical hover (MC MixerProfile 2), the differential thrust from the motors provides *Stabilized Roll* action.
*Stabilized Yaw* action is provided by the ailerons. And *Stabilized Pitch* by the elevator.

### Step 3

- One part of Tailsitter setup that is easy to overlook in the mixers is SWAP ROLL and YAW. And INVERT ROLL. The diff template has them added in the Programming framework Tab. In LC 0, 1 and 2. 
In INAV 10 it will swap the motor and servo stick input by default, so they may not be required for some pilots. It will depend on the Stick mode you use on your radio.    
Some pilots fly FPV and some also fly Line of Sight. So when the plane transitions to a nose upward stance. It will depend on whether you want your Roll and Yaw stick control to also swap.   
This is understandable for a conventional VTOL, but not so much for a Tailsitter. Because hovering nose up isn't any different (by control stick input) than climbing vertically as an airplane.


### Other related information

The Tailsitter diff template will load the required settings for these functions to operate. But it is useful to understand what some of these settings do.

- `tailsitter_orientation_offset = ON` automatically rotates the IMU and Magnetometers orientation offset so it always maintains a 0° gravity reference as the planes axis transitions to 45° and then to 90° in MC VTOL mode (nose-up). The baseline board alignment is set in fixedwing MixerProfile 1.
- `mixer_switch_trans_timer = 30` sets the transition timer to 3s. 
- `vtol_transition_to_fw_min_airspeed_cm_s = 1111` sets the transition airspeed to 35km/h. Which is enough for forward flight when the motors are already producing hover thrust. **I would not increase the transition speed higher than 45km/h, it will lead to control surface oscillations, due to the tight MixerProfile 2 PID tune required for hover stability.**
- Always use ANGLE mode as the base flight mode when flying in MC VTOL mode. It uses the earth frame LEVEL controller. Acro mode will not provide enough hover stability to control most Tailsitter aircraft.

:::warning 
The use of navigation auto transition is not recommended for Tailsitters. The MC navigation throttle controller used with Poshold and RTH was not specifically designed to handle fast Z fluctuations while holding XY horizontal position as well. However ALTHOLD with ANGLE mode can handle Z fluctuation much faster, and can be useful. But it doesn't provide a quick bailout. So use with caution.
:::


### Step 4: Test Roll Output in Tailsitter Mode

- Conduct a bench test and see the orientation of the model changes in inav-configurator setup tab

- Arm or force arm (WITH PROPS OFF) and apply roll inputs on your radio.

- When applying left Roll, the right motor will increase speed and the left will decrease. And when you tilt the right wing to the right, the right motor should increase in speed and the left reduce, in response to roll stabilization. Ensure that this is the behaviour in both cases.
- When you apply Yaw stick, the elevon/ailerons will move. Make sure they and the elevator moves to counteract the opposing forces in a Tailsitter hover.

:::info 
Because tailsiiters are a bi-copter, they aren't as vertically stable as other VTOL platforms. This means it is very important to ensure the flight control is perfectly aligned with the planes thrust angle.    
The adjustment can be made using `align_board_roll` and `align_board_pitch`, which can be found in the _Alignment Tool Tab_. It may only require a couple of degrees alignment alteration, but if it's not done, the VTOL will drift horizontally when in a hover in ANGLE mode.   
Unfortunalty there is no easy way to do this. It must be done with the VTOL holding its own weight in an untethered hover.  
:::

## Quad Plane Setup

A Quad-plane has 4 individual lift motors that are used for the Take-off, Hover, Transition and the Landing phase of VTOL flight. When the transition from MC-VTOL to FW flight is complete, they are switched off for forward flight, using the fixedwing motor to propell the airplane and conserve the battery.  
QuadPlanes are the heaviest VTOL platform, but they are also the easiest to setup, and the most stable in windy conditions.

:::tip
Depending on the quadcopter motor boom mounting position you choose. It maybe beneficial to select Props_OUT or Props_IN, to account for a quad X or quad + format. This option will allow the Yaw rotation to work more effectively, because of the Yaw cancellation that can occur from boom flex/twist on certain builds, which opposes the torque action that drives the Yaw axis.  
It can also be beneficial when using Props_OUT, to tilt all the MC lift motors in-wards 1 - 2° (towards the fuselage). This will also enhance Yaw effectiveness. Do the opposite for Props_IN.
:::

### Lift motors and wing incidence

Mounting the motor booms may seem straight forward. You just mount them to the bottom of each wing with a 3D printed mount, or sideways through the front and rear of the fuselage ?? But a critical step can be easily overlooked when doing this.  
It is important that the airplanes "Angle of Incidence" be accounted for. Most airplanes, when flying level, have between 2 - 6° positive incidence on their wing. This is so the aerofoil produces its optimal lift in forward flight.   
But you do NOT want the motors with their propellers having that same incidence angle. The propellers of all 4 lift motors must be parallel to the incoming air flow when the airplane is flying with its specific incidence angle.  
If this isn't accounted for. The airplane will loose altitude during transition, even if you apply up elevator, because the lift motors will fight the wings natural incidence as forward speed is increasing. This occurs due to the lift motors pushing their thrust downwards, but also slightly forwards, causing a braking effect.  
But it can be mitigated a little by lowering `vtol_transition_mc_authority_min_percent`.  
The image below shows how your hardware is best aligned. It can be useful to workout this angle using fw AutoTrim before you print the boom mount or motor shims.

### Motor Transition Mixing: Dedicated Forward Motor Configuration

The fixedwing propulsion motor is driven as normal in MixerProfile 1.   
Make sure you are in MixerProfile 1, then go to the **Mixer Tab** > **Motor mixer**. Based on the setup template you loaded. You will see motors 1 to 4 are orange, with -1 under the Throttle[T] mixer. -1 or orange means that motor will not be mixed to the Output.  
But motor 5 will not be orange. it will be 1, which means it is 100% mixed to the Output. That indicates only motor mixer 5 (the fixedwing motor) will be operational in MixerProfile 1. The other 4 motor positions are just place holders.

![Quad plane Mix](/img/features-adv/vtol-mixerprofile-4puls1-mix.png)

### Motor Transition Mixing: MC VTOL Lift Motor Configuration

The Multicopter VTOL motors are driven in MixerProfile 2.  
Make sure you are in MixerProfile 2, then go to the **Mixer Tab** > **Motor mixer**. Based on the setup template you loaded. You will now see motors 1 to 4 are not orange, with 1 under each Throttle[T] mixer. This means those 4 motors will be active in MixerProfile 2 and the Transition mode state.  
But when you now look at motor 5, which is the fixedwing motor. It **will** be orange, which is normal due to its value being greater than -1. This is because Throttle[T] mixer 5 corrisponds to the throttle value used to drive the fixedwing motor during the MC VTOL to FW Transition phase. **It will ONLY be operational in the Transition phase**.

### MC-VTOL mixer weights 

Ideally a Quadplane should have the front and rear motors equally spaced for/aft of the airplanes C.G. This ensures the front and rear motors are applying equal thrust when Throttle, Pitch and Roll commands are given.   
The flight controller can handle a small offset. But if it's too great, the stabilization command will momentarily over-drive the motors carrying the lesser load. This can lead to hover instability.  
However if you do find your build has a little too much motor offset from the airplanes C.G.. It is possible to calculate the offst and lower the mixer weights of the motors carrying the lesser load. This should be applied to the Roll[R] and Pitch[P] axis mixers. Do not lower the Throttle[T] mixer weight on those motors. And never take the mixer weight below 0.65.

:::warning
Airmode type must NOT be set to "THROTTLE_THRESHOLD".
If set to `throttle_threshold`, the (-)Throttle mixer sign, will cause the fixedwing motor to spin at idle during VTOL take-off, until the throttle-threshold (us) is exceeded.
:::



## Automated Switching (RTH):


When configured correctly, the model will use the Fixed-Wing (FW) mode to efficiently return home and then transition to Multi-Copter (MC) mode for easier landing.

To enable this feature, type following command in cli

1. If the model is in MC VTOL mode and a FS/RTH is triggered. These settings will allow it to transition back to FW flight mode via `vtol_autotransition_always = ON `.
With the setting below in the Master and MixerProfile 2. Transition will commence and be complete when either of these occur first. The airspeed reaches 60km/h or the 4.5s transition timer expires.   

```
# master

set nav_rth_allow_landing = FS_ONLY (or ALWAYS)
set vtol_transition_to_fw_min_airspeed_cm_s = 1667
set vtol_autotransition_always = ON
set vtol_mc_protection_mode = NAV
```

```
# mixer_profile
mixer_profile 2

set mixer_automated_switch = ON
set mixer_switch_trans_timer = 45
set mixer_vtol_transition_dynamic_mixer = ON
set mixer_vtol_manualswitch_autotransition_controller = ON
set mixer_vtol_transition_airspeed_timeout_ms = 6000

```

2. When the airplane reaches the home location after a FS/RTH, it will transition back from a fixedwing to a MC VTOL and commence a landing via `vtol_autotransition_always = ON` .
Transition time is only 0.7s with no airspeed check. Because you want the airplane to slow as quickly as possible, so it doesn't have to reverse too far back to the home location.

```
# mixer_profile
mixer_profile 1

set mixer_automated_switch = ON
set mixer_switch_trans_timer = 7
set mixer_vtol_transition_dynamic_mixer = ON
set mixer_vtol_manualswitch_autotransition_controller = ON

```

3. Save your settings. type `save` in cli.

If you set `mixer_automated_switch = OFF` for both mixer profiles (the default setting), the model will not perform automated transitions. You can always enable navigation modes after performing a manual transition.

## Notes and Experiences

### General

- VTOL model operating in multi-copter (MC) mode may encounter challenges in windy conditions. Please exercise caution when testing in such conditions.
- Make sure you can recover from a complete stall before trying the mid air transition
- It will be much safer if you can understand every line in diff all, read your diff all before maiden

### Tilting-Rotor

- In some tilting motor models, you may experience roll/yaw coupled oscillations when `MIXER TRANSITION` is activated. To address this issue, you can try the following:
  1. Use prop blade meets at top/rear prop direction for tilting motors to balance the effects of torque and P-factor.
  2. In addition to 1. Add a little yaw mixing(about 0.2) in tilt motors.
- There will be a time window that tilting motors is providing up lift but rear motor isn't. Result in a sudden pitch raise on the entering of the mode. Use the max speed or faster speed in tiling servo to reduce the time window. OR lower the throttle on the entering of the FW mode to mitigate the effect.

### Dedicated forward motor

- Easiest way to setup a vtol. and efficiency can be improved by using different motor/prop for hover and forward flight
